# Aurora Servicios

Sitio web de servicios hecho en equipo con HTML, CSS y JavaScript.

- **Página principal:** menú y descripción de 2 servicios.
- **Servicio 1: Barbería Navaja Neón** (Estudiante 1), rama `feat/detalleservicio1`.
- **Servicio 2: Estudio de Yoga Prana** (Estudiante 2), rama `feat/detalleservicio2`.

Abre `index.html` en el navegador para ver el sitio.
